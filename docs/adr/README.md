# Architecture Decision Records

ADRs documentam decisões arquiteturais significativas.

## Formato

- Um arquivo por decisão: `NNNN-titulo-curto.md`
- Status: proposed | accepted | deprecated | superseded
- Seções: Contexto, Decisão, Consequências

## Workflow

1. Proponha ADR em PR.
2. Revise com o time.
3. Marque como `accepted` ao mergear.

Veja `0000-record-architecture-decisions.md` para a meta-decisão de usar ADRs.
