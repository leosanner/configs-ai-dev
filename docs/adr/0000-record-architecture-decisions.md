# 0000. Record architecture decisions

## Status

Accepted

## Contexto

Precisamos registrar decisões arquiteturais de forma rastreável.

## Decisão

Usamos Architecture Decision Records (ADRs) neste diretório, numerados sequencialmente.

## Consequências

- Decisões ficam versionadas com o código.
- Novos contribuidores leem o histórico de decisões antes de propor mudanças grandes.
